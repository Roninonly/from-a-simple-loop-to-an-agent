# 青竹 Agent 学习营：RAG 测试资料

本文中的学习营、人物和规则均为教学虚构，仅用于本项目的知识库检索测试，不代表真实机构或用户信息。

## 学习营基本信息

学习营名称：青竹 Agent 学习营。
学习营内部编号：QZ-417。
学习营助教：林舟。
每周答疑时间：星期三晚上 20:15 至 21:00。
答疑地点：线上青竹讨论室。

## 作业提交规则

每周作业的提交截止时间：星期日晚上 21:30。
提交材料包括：Python 源代码、运行截图和一份简短的学习总结。
禁止在提交材料中包含真实 API Key 或 .env 文件。
作业文件命名格式：学员昵称_阶段编号.zip。

## 阶段验收规则

工具调用阶段：需要展示计算器工具和当前时间工具各成功调用一次。
会话记忆阶段：需要展示两个会话相互隔离，以及程序重启后恢复同一会话的历史。
知识库阶段：需要展示检索到的文档片段，并在回答中说明资料来源。

## 设备借用规则

学习营共有 7 台测试设备。
每位学员一次最多借用 1 台，最长借用 3 天。
设备申请需要联系助教林舟，并提供学员昵称和预计归还日期。
