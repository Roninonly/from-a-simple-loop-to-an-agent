# Agent 学习版本存档

这个目录保存每个阶段完成时的代码快照，方便以后对照学习。

- `v0/`：只支持连续聊天的 LLM Chat Agent。
- `v1/`：支持 Tool Calling 的 Tool-Using Agent。
- `v2/`：使用 LangGraph 状态图管理模型和工具循环的 Agent。
- `v3-memory/`：阶段 3 的中间版本，支持内存会话记忆和会话切换。
- `v3/`：完整的阶段 3，使用 SQLite 保存会话，支持程序重启后恢复。
- `v4/`：完整的阶段 4，在 V3 基础上加入本地中文向量化和知识库检索工具。
- `v5/`：阶段 5 的基础快照，保留会话记忆和 RAG，通过 MCP 调用本地时间工具。
- `v5-auto/`：阶段 5 的多工具自动发现版，自动接入时间、计算器、文字计数工具。
- `v6/`：完整的阶段 6，以 FastAPI 提供 HTTP 接口，终端与接口共用智能体服务。
- `v7/`：完整的阶段 7，增加最小评估题库、真实执行、分项指标和本地 JSON 报告。
- `v8/`：完整的阶段 8，增加 Dockerfile、.dockerignore，并验证本地容器运行和命名卷会话持久化。
- `v9/`：极简聊天网页版，支持发送问题、切换会话和从后端恢复历史显示，保留此前全部能力。

根目录中的 `main.py`、`app/` 及 `eval/` 是正在继续开发的最新版。版本存档不会复制
根目录的 `.env`，避免真实 API Key 出现在多个文件中。

在项目根目录运行某个历史版本，例如：

```powershell
python .\versions\v1\main.py
```

历史版本共用根目录的 `.env`，但每个版本保存自己的 `requirements.txt`，
这样以后仍能看出该阶段实际需要哪些依赖。

V3 的数据库位于所运行 main.py 同级的 data 文件夹。
根目录程序与 v3 历史快照使用各自的数据库，便于独立复现。
版本存档不会复制聊天数据库；v3-memory 仍是关闭后丢失记忆的内存版。

V4 快照包含自己的 rag.py 和虚构测试文档，数据库、模型缓存也放在
versions/v4/data 下，与根目录版本隔开。首次运行快照可能需要下载模型。
不会复制真实 .env、会话数据库或模型缓存；完整报告见 v4/README.md。

V5 快照额外包含 mcp_client.py 和 mcp_server.py。时间工具通过 MCP 调用，
计算器与 RAG 仍在 Agent 进程内执行。数据库与模型缓存位于 versions/v5/data，
不会复制根目录运行数据。完整报告及运行方式见 v5/README.md。

V5 自动发现版保存在 v5-auto，原 v5 文件保持不变，便于比较两种接入方式。
v5-auto 的数据库与模型缓存也使用自己的 data 目录，不复制真实运行数据。
完整阶段报告和调用关系见 v5-auto/README.md。

V6 快照包含 app/ 后端包，保留终端入口；HTTP 与终端共用 AgentService。
其数据库和模型缓存位于 versions/v6/data，不复制真实运行数据。
V6 的配置读取位置明确指定为当前版本根目录，运行历史快照时需要显式加载
原项目 .env，而不是假设自动向上搜索；可使用 Uvicorn 的 --env-file 参数。
完整命令、函数调用关系和验收结果见 v6/README.md。

V7 快照保留 V6 所有能力，额外包含 eval/dataset.json 和 eval/evaluator.py。
默认只预览题库，--run 才请求模型；评估使用临时会话数据库，不污染日常聊天历史。
运行报告保存在各版本自己的 eval/results/，不复制开发版生成的报告。
配置、模型缓存和 HTTP 启动方式延续 V6 的隔离原则；运行快照评估前需显式加载
原项目 .env。完整启动命令、指标口径和真实验收记录见 v7/README.md。

V8 快照保留 V7 业务源码并加入 Docker 构建配置。镜像不包含真实 .env、
日常数据库或模型缓存；历史快照可以从 versions/v8 单独构建镜像。
本阶段在 Windows 的 Docker Desktop 上验证了 HTTP 接口与命名卷跨容器重建保存会话。
卷的数据由 Docker 管理，不在 Git 快照中；详细命令、证据和限制见 v8/README.md。

V9 在 V8 基础上增加 app/static/index.html、首页和历史查询接口。
网页聊天与会话切换已有用户使用反馈，历史首次加载也已有反馈；
切换历史的恢复显示、错误分支及容器内新版运行的验收范围见 v9/README.md。
快照不含真实 .env、数据库或缓存；复现时需显式加载原项目环境配置，
数据库与模型缓存写入 versions/v9/data，与根目录版本隔开。
