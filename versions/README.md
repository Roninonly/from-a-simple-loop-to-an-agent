# Agent 学习版本存档

这些阶段提交依据已存快照事后重建，非原始逐步开发记录。

- [v0](v0/)：V0：实现模型连接与最小连续对话循环。
- [v1](v1/)：V1：增加计算器、时间工具与手写工具调用循环。
- [v2](v2/)：V2：用 LangGraph 状态图管理模型与工具调用。

- [v3](v3/)：V3：使用 SQLite 持久化会话并支持重启恢复。
- [v4](v4/)：V4：增加中文文档向量化与 RAG 知识库检索。
- [v5](v5/)：V5（基础版）：通过本地 MCP 服务调用时间工具。
- [v5-auto](v5-auto/)：V5：自动发现并接入多个 MCP 工具。
- [v6](v6/)：V6：封装共享智能体服务并提供 FastAPI 接口。
